# OCI + SEA Community Hub

Repositorio comunitario para compartir **guías, buenas prácticas, templates y ejemplos reproducibles** en **Oracle Cloud Infrastructure (OCI)**, enfocado en **Southeast Asia (SEA)**.

## Contenido
- `docs/` Guías y mejores prácticas
- `examples/` Ejemplos (Terraform/CLI/SDK)
- `templates/` Plantillas reutilizables
- `.github/` Templates de Issues/PR

## Quickstart
1) Lee `docs/getting-started.md`  
2) Ve a `templates/` para empezar rápido  
3) Usa `examples/` para casos concretos
